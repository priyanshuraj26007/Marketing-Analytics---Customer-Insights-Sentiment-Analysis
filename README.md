# Customer Shopping Behavior Analysis | End-to-End Data Analytics Project

## Project Overview

The objective is to transform raw transactional data into actionable insights that help businesses understand customer purchasing behavior, identify revenue drivers, and make data-driven decisions.

---

# Project Objectives

* Clean and prepare raw customer shopping data
* Perform Exploratory Data Analysis (EDA) using Python
* Load and manage data in a SQL database
* Solve real-world business problems using SQL
* Build an interactive Power BI dashboard
* Generate business insights and recommendations

# 📊 Project Components

## 1️⃣ Data Cleaning & Preparation (Python)

Performed comprehensive preprocessing to improve data quality.

Tasks included:

* Importing the dataset
* Handling missing values
* Removing duplicates
* Correcting data types
* Data transformation
* Feature preparation
* Initial exploratory analysis

---

## 2️⃣ Exploratory Data Analysis (EDA)

Performed statistical and visual analysis to understand customer behavior.

Some of the analyses include:

* Customer demographics
* Purchase amount distribution
* Product category analysis
* Seasonal shopping trends
* Discount usage
* Customer segmentation
* Revenue contribution by different customer groups

---

## 3️⃣ SQL Business Analysis

Loaded the cleaned dataset into MySQL and solved multiple business problems using SQL.

Some business questions answered include:

* Total revenue by gender
* Top spending customers
* Highest-selling product categories
* Revenue by season
* Impact of discounts on purchase behavior
* Loyalty analysis
* Average purchase amount
* Customer segmentation
* Shopping frequency analysis
* Product performance

SQL concepts used:

* GROUP BY
* HAVING
* Aggregate Functions
* CASE Statements
* Subqueries
* Joins
* Window Functions
* CTEs
* Ranking Functions

---

## 4️⃣ Power BI Dashboard

Created an interactive dashboard to visualize business performance.

Dashboard includes:

* Revenue Overview
* Customer Demographics
* Product Category Performance
* Seasonal Trends
* Discount Analysis
* Purchase Distribution
* Customer Segmentation
* Interactive Filters and Slicers
